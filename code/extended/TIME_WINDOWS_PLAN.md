# Time-window comparison

An exploratory comparison using the same coded dataset:

- Full calendar years: 2022-2025.
- Matched January-August windows: 2022-2026.

Every observed label is retained with its count, valid denominator, missing and
special-state counts, and known-only share. Association and decomposition methods
are unchanged from the base analysis. Early or sparse groups are flagged.

Window effects are compared using the common 2022-2025 endpoints, so adding 2026
is not mistaken for a calendar-window effect. The two windows overlap and are not
independent replications. Cohort sizes, date boundaries, annual counts and the
2024-2026 matched decomposition are checked against base outputs.
