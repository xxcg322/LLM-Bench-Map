# Selected development findings

These files retain coded findings from five targeted interaction checks and twenty
preselected language checks conducted during development, with narrative notes
omitted. They are reused only for comparison with the final coding outputs.

They are exposed, selected, AI-assisted source checks, not a new independent human
sample or an estimate of population accuracy. The error-sensitivity script records
their correspondence with the final dataset; its numerical error budgets remain
hypothetical and are not fitted to these findings.
